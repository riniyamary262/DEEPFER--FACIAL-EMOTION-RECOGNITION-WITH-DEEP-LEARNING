**TECHNICAL ARCHITECTURE**

The system uses a dataset that has than 71,000 images. There are 28,000 or more images for training and 7,000 or more images for testing. The images are split evenly across seven emotions. All the images are made into 48 by 48 grayscale pixels. These images come from the FER2013 dataset. The custom CNN architecture has four blocks. Each block has two layers. Each block has batch normalization, ReLU activation, max pooling and dropout regularization. The first block has 32 filters. The second block has 64 filters. The third block has 128 filters. The fourth block has 256 filters. Each block has a dropout rate of 0.25. The architecture uses average pooling instead of flattening. This helps to reduce the number of parameters. Then there are layers with 256 and 128 neurons. These layers have a dropout of 0.5. The final layer is an output layer with 7 neurons. This is, for emotion classification. Important parts of the design include batch normalization. This helps the training go faster and be more stable. Dropout regularization is used to stop overfitting. Global average pooling helps to reduce parameters. ReLU activation helps with learning. The Adam optimizer is used with a learning rate. The system also has another model that uses transfer learning. This model is based on the VGG16 style. Data augmentation methods are used. These methods include rotating the images by ±30 degrees. There is also height shifts of ±20 percent. Shear is applied at ±20 percent. Zoom is done at ±20 percent. The images are flipped horizontally. Brightness is adjusted between 0.8 and 1.2. The images are also rescaled to 1/255.

**IMPLEMENTATION DETAILS**

The implementation uses TensorFlow and Keras for deep learning, Python 3.10+ as the programming language, PIL and OpenCV for image processing, NumPy, Pandas, and Scikit-learn for data analysis, and Matplotlib and Seaborn for visualization. The data loading process involves traversing directory structures to load images and labels, applying preprocessing and augmentation, and creating data generators for efficient batch processing. Model training utilizes early stopping with patience of 15 epochs to prevent overfitting, model checkpoint to save the best weights, and reduce learning rate on plateau with factor 0.5 and patience of 5 epochs. Class weights are computed to handle imbalance, and training runs for up to 50 epochs with a batch size of 32 and learning rate of 0.001. Prediction involves loading and preprocessing the image, passing it through the model, and returning the predicted emotion with confidence score.
